How to play Half-Life on a Chromebook in 2026

Platform guideChromeOSUpdated August 2026

Most guides you'll find for this tell you to install Steam for ChromeOS. Don't — it no longer exists.

Steam for Chromebooks ended on 1 January 2026. Google and Valve shut down the beta rather than graduating it, and games installed through it no longer run. If you followed a guide that told you to enable it, that guide predates the shutdown.

The good news is that Half-Life is unusually well suited to what's left. Valve ships official Linux builds of both Half-Life and Half-Life 2, and every Chromebook has a Linux environment. So unlike almost every other Windows game, Half-Life doesn't need a translation layer here — it runs natively.

Method 1 — Linux + Steam (the real thing)

ChromeOS includes a Linux development environment. It is entirely separate from the discontinued Steam for ChromeOS beta and is still fully supported.

01 Turn on the Linux environment

Open Settings › About ChromeOS › Developers, find Linux development environment and turn it on. When it asks for a disk size, give it more than the default — Half-Life 2 plus Steam wants roughly 10 GB, and growing the disk later is more annoying than sizing it right now.

02 Install Steam inside Linux

Open the Linux terminal and install the Steam client from the Debian repositories. Download Valve's official .deb package, then install it — the package manager will pull in the graphics and 32-bit libraries it needs.

You are installing Steam for Linux, the same client used on desktop Linux. This is not the removed ChromeOS beta and is not affected by its shutdown.

03 Install Half-Life normally

Sign in, find Half-Life in your library, and install it. Because Valve publishes native Linux builds, there is no Proton step and no compatibility settings to fight with.

If a title in your library shows as unavailable, it has no Linux build — enable Steam Play in Steam's settings to run it through Proton. For Half-Life and Half-Life 2 you won't need to.

ARM Chromebooks: if your machine has a MediaTek or Snapdragon chip rather than Intel or AMD, the x86 Steam client won't run. Skip to method 2 or 3.

Method 2 — Xash3D FWGS (Android app)

ChromeOS runs Android apps, and Xash3D FWGS is an open-source reimplementation of the GoldSrc engine with an Android build. It runs Half-Life 1 from the game's own data files.

This is the best option on a weak or ARM Chromebook. Half-Life 1's requirements are from 1998, so it runs comfortably on hardware that would struggle with anything else.

You must own the game. Xash3D is an engine, not a copy of Half-Life — it needs the valve folder from an installation you own. Copy that folder across and point the app at it. Distributing those files is piracy; using your own is not.

The trade-off: this is Half-Life 1 only. Half-Life 2 runs on Source, which Xash3D does not implement.

Method 3 — Cloud gaming

Streaming shifts the work to a remote machine and sends you video, which makes even the cheapest Chromebook irrelevant to performance. Services like GeForce NOW, Shadow and Boosteroid all run in the browser.

Two caveats worth knowing before you subscribe:

  • Catalogue coverage varies. Streaming services support specific title lists, and older games are not always included. Check that the exact game you want is supported before paying.
  • Input lag is real. For a slow strategy game it doesn't matter. For a shooter where you're leading a headcrab jump, it does. A wired or strong 5 GHz connection makes a large difference.

Given that Half-Life runs natively on the Linux route, cloud gaming is mainly worth it if you're on an ARM Chromebook and want Half-Life 2.

Which should you pick?

  • Intel or AMD Chromebook — Method 1. Native Linux builds, no compromises, both games.
  • ARM Chromebook, Half-Life 1 — Method 2. Light, fast, works well.
  • ARM Chromebook, Half-Life 2 — Method 3, or play on something else.
  • School-managed Chromebook — probably none of them. Managed devices usually have the Linux environment and app installs blocked by policy, and that is set by your administrator, not by you.

Frequently asked

Can I get my Steam for ChromeOS games back?

Not through that route — the beta is closed. Your Steam account and licences are unaffected, so anything you own can be reinstalled through Linux Steam or played on another device. You lost the ChromeOS client, not your games.

Does Half-Life really run natively on Linux?

Yes. Valve has shipped Linux builds of Half-Life and Half-Life 2 for years. It's one of the reasons Half-Life remains a good fit for Chromebooks and Steam Deck alike.

How much storage do I need?

Budget around 10 GB for the Linux container with Steam and Half-Life 2. Half-Life 1 alone is tiny — well under 5 GB including the client.

Will mods work?

GoldSrc mods that are plain data — maps, models, sounds — generally work on Linux. Mods shipping compiled Windows libraries do not, because those are Windows binaries. That rules out most gameplay overhauls. See our mod guides for which is which.

Why not just use Android's Steam Link app?

Steam Link streams from a gaming PC you already own on the same network. If you have one, it's an excellent option. If you don't, there's nothing to stream from — which is usually the situation people asking this question are in.
