Half-Life versions and editions

Section indexGoldSrc & SourceUpdated 2026

Twenty-five years of releases, re-releases and updates have left a trail of edition names that mostly no longer mean anything. Here's what each one was, and which of them still affects a purchase today.

If you only want the answer: buy the standard digital release. It has every official update applied and is more complete than any boxed edition ever sold — Game of the Year Edition included.

Half-Life 1 — the timeline

ReleaseWhat it wasMatters today?
Original (1998) The game as shipped Historical only
Game of the Year Edition (1999) Same campaign, bundled with Team Fortress Classic, Uplink and the free updates No — everything it added is now standard
Steam release Continuously updated digital version This is what you buy
25th Anniversary update (Nov 2023) Rebuilt engine internals, added Uplink, four new multiplayer maps, restored content, Steam Deck support Yes — the current default, and it broke a lot of mods
steam_legacy branch Archived Pre-25th Anniversary Build Only if a mod requires it

Half-Life 2 — the timeline

ReleaseWhat it wasMatters today?
Original (2004) The game as shipped Historical only
Episodes & Lost Coast Separate products with their own library entries Now reachable from Half-Life 2's own menu
20th Anniversary update (Nov 2024) Added Steam Workshop support, developer commentary, graphics options, bug fixes; folded in the episodes Yes — the current default
steam_legacy branch Archived Pre-20th Anniversary Build Only if a mod requires it

The one trap worth knowing

Both games have a branch called steam_legacy, and they are not the same thing. Half-Life's rolls back to the Pre-25th Anniversary Build (2023); Half-Life 2's rolls back to the Pre-20th (2024). Setting one does nothing for the other — and each rollback is a multi-gigabyte download, so getting it wrong costs real time. Full explanation of both.

Frequently asked

Is there a remastered Half-Life?

Not an official one. The anniversary updates improved both games substantially but aren't remasters. Black Mesa is a fan remake of Half-Life 1 built on Source, released standalone with Valve's permission — the closest thing that exists.

Do the expansion packs get updates too?

Opposing Force and Blue Shift are separate Steam products with their own update histories and their own Betas tabs. Check each individually rather than assuming the base game's settings apply.

Which version do mods target?

It varies, and it's the single most common source of mods not working. Anything built before November 2023 targets the pre-anniversary GoldSrc engine — see installing GoldSrc mods.
