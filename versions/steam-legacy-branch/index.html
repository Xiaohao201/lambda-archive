The steam_legacy branch — what it is and when to use it

Version guideHalf-Life (GoldSrc)Updated 2026

If you've been troubleshooting a Half-Life mod, you've been told to "switch to steam_legacy" — usually without any explanation of what that is or what it costs you. Here's both.

In one line: steam_legacy is the version of Half-Life from before the 25th Anniversary update, kept available as a public beta branch so that older mods still run.

Why the branch exists

The 25th Anniversary update, released in November 2023, rebuilt significant parts of the GoldSrc engine. That was good for the game and bad for a mod scene with a quarter-century of accumulated work built against the old engine — a large share of mods and the official expansion packs stopped running correctly.

Rather than leave that content stranded, Valve archived the previous build as a publicly visible beta branch labelled Pre-25th Anniversary Build. Anyone can select it, no access code needed.

It's an escape hatch, not a supported alternative. Valve has stated that it considers the anniversary build the definitive version and the one it will continue to support.

How to switch

01 Open the game's properties

Right-click Half-Life in your Steam library and choose Properties.

02 Select the branch

Open the Betas tab. In the branch dropdown, choose steam_legacy. You don't need a beta access code — leave that field empty.

03 Let it download

Close the properties window. Steam replaces your game files with the older build. This is a substantial download, not a small patch, and it takes as long as reinstalling.

When it finishes, launch your mod. If the engine version was the problem, it will now work.

Your saves are safe. Switching branches changes game files, not save games. Nothing you've played is lost either direction.

What you give up

This is the part the "just use steam_legacy" advice always omits. The anniversary update wasn't only engine changes — it added real content, and rolling back removes all of it:

Multiplayer is the sharpest edge here. You're on a different build from most of the player base, and the four new maps don't exist for you.

When it's the right call

Switch if:

  • A mod you specifically want to play doesn't run on the current build, and it has no compatibility patch.
  • You're replaying an official expansion pack that's misbehaving.
  • You're playing single-player and don't care about the anniversary additions.

Don't switch if:

  • You haven't checked whether the mod released a compatibility patch. Many actively maintained ones did, and a patch is strictly better — it leaves your install current.
  • Your problem isn't actually the engine. A mod that's missing from your library or crashing at map load usually has a different cause — see the five-cause troubleshooting order.
  • You play multiplayer regularly.

Check for a patch first. Rolling back the whole game to run one mod is the blunt instrument. A mod-side compatibility patch solves the same problem without giving up anything, and takes a minute to look for on the mod's ModDB page.

Half-Life 2 has one too — and it's different

This catches people out, because the branch has the same name in both games and rolls back to entirely different things.

A year after Half-Life's anniversary update, Half-Life 2 got its own — the 20th Anniversary Update of 16 November 2024, which added Steam Workshop support, developer commentary, graphics options and bug fixes, and folded Episode One, Episode Two and Lost Coast into Half-Life 2's own menu. Valve archived the previous build the same way.

Setting one does nothing for the other. They're separate Steam products with separate Betas tabs. If a Half-Life 2 mod is broken, switching Half-Life 1 to steam_legacy changes nothing at all — a surprisingly common wasted download.

The same advice applies in both cases: look for an updated version of the mod first, and treat the rollback as the fallback. For what Half-Life 2's update added, see the Half-Life 2 Workshop guide.

Switching back

Same path, opposite direction: Properties › Betas, then select None from the dropdown. Steam re-downloads the current build.

There's no penalty and no limit on how often you switch, so treating it as a temporary mode for a specific mod is perfectly reasonable. The only real cost is bandwidth and the time each download takes.

Frequently asked

Do I need a beta access code?

No. steam_legacy is a public branch — select it from the dropdown and leave the code field empty.

Is Half-Life 2's steam_legacy the same branch?

No. Same name, different game, different rollback. Half-Life's is the Pre-25th Anniversary Build (November 2023); Half-Life 2's is the Pre-20th Anniversary Build (November 2024). Each is set independently on its own product.

Do the expansion packs have their own legacy branches?

Opposing Force and Blue Shift are separate Steam products with their own Betas tabs. Check each one individually rather than assuming the base game's setting carries over.

Will my mods break when I switch back?

Mods that only work on the legacy engine will stop working again on the current build — that's the same incompatibility, not new damage. The mod files themselves are untouched.

Is steam_legacy going away?

Valve hasn't announced an end date. It's an archival branch rather than a maintained one, so it receives no updates — but it also has no announced removal.

Does this work on Steam Deck or Linux?

The branch selector works the same everywhere. Note that Steam Deck support was one of the anniversary additions, so the legacy build is a worse fit for that hardware specifically.
