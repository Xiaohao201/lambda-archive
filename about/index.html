About Lambda Archive

Lambda Archive is an independent reference site for Half-Life. It exists because the information people actually need — which Steam edition to buy, why a mod refuses to launch, what a given NPC actually says — is currently scattered across forum replies, buried in wiki pages loaded with six ad units, or locked inside a twelve-minute video.

What we publish

  • Mod guides and troubleshooting. Install walkthroughs and failure diagnostics for the mods people are actively trying to run.
  • Voice line transcripts. Complete, searchable text for the game's NPCs, with the context each line is triggered in.
  • Platform and version guides. Straight answers about which release to buy and where the games will and won't run.
  • Character and lore references. Short, factual profiles rather than speculation essays.

How this material is checked

Technical instructions are verified against primary sources before publication — the mod author's own ModDB or GitHub page, Valve's official announcements, and the game's own files. Where the community has settled on a fix that isn't officially documented, we say so rather than presenting it as official.

Mods change. Engines get updated. When a guide stops matching reality we would rather hear about it than leave it up — every page carries a link to contact us, and corrections are made promptly.
