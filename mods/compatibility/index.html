What the labels mean

  • Supported or recommended: the author explicitly targets that build or recommends using it.
  • Partial: the mod can run, but a documented feature, interface element or common configuration is broken.
  • Unverified: no sufficiently reliable current statement was found. It does not mean incompatible.

How entries are checked

Author posts, release descriptions and maintainer replies are used before community reports. A community workaround is labelled as such. Comments saying only that a mod "works for me" are not enough to mark a whole build supported.

Sources checked for this release: the official ModDB pages for Brutal Half-Life, Half-Life: Insecure, and Cat-Life: GS.

Before blaming compatibility

A correct build cannot rescue a broken folder structure. GoldSrc mods belong directly inside the Half-Life directory, beside valve, and liblist.gam must sit at the top level of the mod folder. See the GoldSrc installation guide before changing branches.

Found a correction? Include the mod version, Steam branch, operating system and a link to the author's statement or release notes. Send it through the contact page; compatibility claims are changed only when they can be checked.
