How to use ReShade on Half-Life 2

Setup guideSource engineUpdated 2026

ReShade is a post-processing injector — it sits between the game and your GPU and applies effects to the finished frame. It doesn't modify Half-Life 2 itself, which makes it one of the safest visual upgrades available and trivially reversible.

The setup takes about five minutes. Almost everything that goes wrong comes down to two choices made in the installer, so get those right and the rest is straightforward.

The short version: pick hl2.exe, choose DirectX 9, and turn off anti-aliasing before you start. Those three things account for most failed installs.

Do this before installing

Turn off anti-aliasing in two places. This is strongly recommended and skipping it is a common source of blurry or broken output:

  1. In Half-Life 2: Options › Video › Advanced, set anti-aliasing to None.
  2. In your GPU control panel (NVIDIA Control Panel or AMD Software), make sure no anti-aliasing is being forced on Half-Life 2.

ReShade's own effects handle edge smoothing, and forced MSAA fights with them — most visibly with anything that reads the depth buffer.

Know where your game lives. You'll need to point the installer at hl2.exe, normally at:

Steam\steamapps\common\Half-Life 2\hl2.exe

Installing ReShade

01 Run the setup and select the game

Download ReShade from reshade.me and run ReShade_Setup. Click the browse box, navigate to your Half-Life 2 folder, and select hl2.exe.

02 Choose DirectX 9 — not 10, 11, or 12

When the installer asks for the rendering API, select DirectX 9.

Half-Life 2 runs on Valve's Source engine, which renders through Direct3D 9. Picking a newer DirectX version installs a hook the game never calls, so ReShade simply never loads — no error, no overlay, nothing. This is the single most common mistake in ReShade setups for Source games.

03 Install a shader package

The installer offers to download effect packages. Take the standard one on your first install — it includes the widely used effects and is what almost every preset expects to find. You can add more later by re-running the setup.

If you're installing a preset someone else made, install it now too; presets reference specific shaders by name and will show errors for anything missing.

The first launch (and the freeze)

Start Half-Life 2. It will very likely appear to hang for one to two minutes.

Do not kill the process. ReShade compiles every installed shader on first run. The game is not frozen, it's working. This happens only on the first launch after installing or updating shaders — subsequent launches are normal speed.

Once loaded, press Home to open the ReShade overlay. On first open you'll get a short tutorial; you can step through it or skip it. The effect list is the main thing — tick an effect to enable it, and changes apply live.

Enabling the depth buffer

Ambient occlusion, depth of field, and most "realistic lighting" presets need access to the game's depth buffer, which tells them how far each pixel is from the camera. ReShade does not expose this by default.

Open the overlay and enable depth buffer access in the add-on/settings tab. If the depth preview shows a flat or inverted image, the depth buffer options in the same panel include toggles for reversed and upside-down depth — one combination will produce a correct grayscale image of the scene.

Multiplayer note: ReShade deliberately blocks depth buffer access in network games, because seeing through walls via the depth buffer would be a cheat. In Half-Life 2 Deathmatch, depth-based effects will not work. This is intended behaviour, not a bug.

When nothing happens

SymptomCause and fix
Home key does nothing, no overlayWrong API chosen — reinstall and select DirectX 9
Overlay opens, but effects do nothingNo effects ticked, or the preset's shaders were never downloaded
AO / DOF have no visible effectDepth buffer not enabled, or you're in a multiplayer session
Game hangs on launch, every timeOnly the first launch should be slow — a repeating hang usually means a broken shader; remove the newest preset
Picture is blurry or edges shimmerAnti-aliasing still forced on in-game or in the GPU control panel
Overlay appears in some Source games but not HL2ReShade was installed to a different Source game's executable

If the overlay never appears, the fastest check is whether the ReShade DLL actually landed next to the executable the game launches. Source games load their binaries from a bin folder, and some installs need the files there rather than in the game root. Re-running the installer and letting it place the files is more reliable than moving them by hand.

Removing it cleanly

Run ReShade_Setup again, select hl2.exe, and choose the uninstall option. That removes the injector, the reshade-shaders folder, and the configuration files.

Because ReShade never touches game files, uninstalling returns Half-Life 2 to exactly its original state. Nothing to verify, nothing to repair.

Frequently asked

Does ReShade work with Half-Life 2 mods and the episodes?

Yes — Episode One, Episode Two and most Source mods use the same engine and the same DirectX 9 path. Each executable needs its own ReShade install, though: installing to hl2.exe does not cover a mod that launches through a different exe.

Will ReShade get me VAC-banned?

ReShade is a widely used post-processing tool and is not a cheat, which is exactly why it blocks depth buffer access in multiplayer. That said, any injector carries some risk with anti-cheat systems, and the cautious choice is to use it in single-player only.

How much performance does it cost?

It depends entirely on which effects you enable. Simple colour grading is nearly free; ambient occlusion and ray-traced-style shaders are expensive. Half-Life 2 is old enough that most modern hardware has plenty of headroom — enable effects one at a time and watch your frame rate.

Can I use someone else's preset?

Yes. Drop the .ini preset file into your ReShade folder and select it from the preset dropdown in the overlay. Make sure you have every shader the preset references, or you'll see a list of errors on load.
